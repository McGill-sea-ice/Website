# We Can Make Blog/News Posts

## Steps by Steps Tutorial

1. Navigate to the `mcgill-sea-ice/Website/_posts` github reposatory.
2. **Create a new markdown file (.md)** following the naming convention `YYYY-MM-DD-name-of-post.md` , so for this post the filename is `2026-09-02-We-have-a-website.md`. 
3. You begin by making a **YAML header**; a header that contains metadata to tell the website compiler what's up with this post (title, tags, etc.). <br>
To Start and End the header add `---` <br>
The content of the YAML header should at least contain

```ruby
---
title: 'Title to show on your post'
date: yyyy-mm-dd
categories:
  - Non Scientific News/ Scientific News / Other # Restrain yourself to those 3 categories
tags:
  - Fieldwork, Model, Etc. # here we can go more wild but I would try to remain somewhat consistent, i.e. name of the author, what your topic is 

classes: wide # OPTIONAL, the classes give additional aesthetic informations
---
```

For example, the header for this post that you are reading is: 
```ruby
---
title: "We Have a Website"
date: 2026-09-02
categories:
  - Non Scientific News
tags:
  - Website
  - Update
  - Damien Robledo Poisson #unsure if we should put full names or not, but Damien Ringeisen 
classes: wide 
---
```

Then <br>
4. Write the content of your post following a markdown style file. 
5. Save your file and push your fork to the main branch for an admin to accept the post 
6. You are done, go online and check it out (after approval ofc)
